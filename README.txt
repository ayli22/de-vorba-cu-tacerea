# De vorbă cu tăcerea — site de prezentare

Proiect HTML, CSS și JavaScript, pregătit pentru deschidere și editare în Visual Studio Code.

## Cum îl pornești
1. Dezarhivează folderul `de_vorba_cu_tacerea_site`.
2. Deschide Visual Studio Code.
3. Alege **File → Open Folder** și selectează folderul proiectului.
4. Deschide `index.html`.
5. Recomandat: instalează extensia **Live Server** în VS Code, apoi click dreapta pe `index.html` → **Open with Live Server**.

## Fișiere
- `index.html` — structura paginii și textele.
- `style.css` — culori, fonturi, layout și adaptarea pentru telefon.
- `script.js` — meniul mobil și animațiile discrete.
- `assets/` — coperta și trei pagini de previzualizare extrase din PDF-ul cărții.

## Personalizări înainte de publicare
- În `index.html`, caută `adresa-ta@email.com` și înlocuiește cu adresa ta reală pentru comenzile prin e-mail.
- În secțiunea „Despre autoare”, înlocuiește blocul cu inițialele `AC` cu o fotografie portret.
- Dacă vrei comanzi prin Instagram, WhatsApp sau un formular real, adaugă datele de contact și putem conecta butonul.
- Prețul și modalitatea de livrare nu au fost completate, deoarece nu apar în informațiile furnizate pentru această versiune.

## Observație
Site-ul folosește fragmente și imagini din volumul furnizat. PDF-ul integral nu este oferit automat spre descărcare.
